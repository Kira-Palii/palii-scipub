# palii-scipub
Проект про Бібліотеку наукових публікацій
Ця тема актуальна, тому що зараз дуже швидко зростає кількість наукових статей, і буває складно зрозуміти, які теми зараз популярні, а які вже втрачають актуальність. Мій проєкт має допомогти відповісти на питання: скільки статей публікується на певну тему і як цей інтерес змінюється з часом. Користуватися цим можуть студенти або дослідники, яким потрібно швидко зорієнтуватися, наскільки активно розвивається якась наукова тема, перш ніж братися за неї. Для аналізу я використовую дані з відкритого API arXiv (можна також Crossref) — це офіційні сервіси, де можна безкоштовно і без реєстрації отримати інформацію про публікації: назву, дату, авторів, тему. Дані я отримую напряму через API, а не вручну і не через парсинг сайту, тому інформація актуальна і її можна отримати у великій кількості (сотні й тисячі записів), що достатньо для аналізу.
